## Validation boundary

For outer test fold f and another outer fold g, an existing OOF prediction for g is generated by a base model trained on all folds except g, which includes f. Reusing those predictions as meta-training features for evaluation on f therefore does not exclude f from the full training graph. The new nested experiment avoids this path by rebuilding meta-training predictions strictly within the outer-training set. This concern is about the proposed legacy stacking evaluation; it is not a quantified estimate of bias in every prior study.
