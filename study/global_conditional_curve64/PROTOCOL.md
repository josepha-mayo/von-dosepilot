# Global conditional full-curve reconstruction at 64 treatment wells

## Goal and distinct hypothesis
Target: halve retained research MSE from 0.001042745722096212 to 0.000521372861048106 without extra treatment wells or worse p90. The target has not been achieved. This experiment asks whether learning a joint distribution of all historical drug-dose-plate measurements can recover missing measurements more accurately than predicting each AUC first and correcting it afterward.

The fixed AUC outputs are exact linear functionals of the full native curves. Estimate a full-curve covariance consisting of global latent factors PLUS drug-local full covariance residuals. Condition on the purchased physical cells, propagate the result through exact AUC quadrature, and optionally apply the existing cross-drug residual kernel. Both complete historical TRAIN plates may be used to learn the population model, but only one 64-well layout is available at inference.

Distinction from the earlier latent_curve_quadrature experiment: that model used independent per-drug PPCA, truncated local rank to purchased-coordinate count, and changed sensor placement. This model keeps the existing R13 64-well plan and uses cross-drug shared factors with full drug-local residual covariance. Distinction from paired-noise conditioning: this models the joint distribution of the full historical physical curve vector and its exact endpoint functional; it is not contrast-only input noise covariance or output whitening. The public historical registry is incomplete, so global novelty against all private prior work is not asserted. The active and completed recent branches were inspected before opening this family.

## Fixed model menu
Four base choices in fixed order: existing own-drug ridge; global conditional with rank 0; global conditional with rank 4; global conditional with rank 12. For the conditional choices: patient-weighted per-well mean, scale=max(SD,0.05), weighted SVD on all fitting curve coordinates; retain the specified global factors; retain within-drug residual covariance after removing those factors; shrink each local residual covariance 10% toward its diagonal; diagonal variance floor 1e-8 in standardized units. The rank-0 model is a declared mechanistic control. No strength sweep after outcome.

For each base apply the unchanged bandwidth-0.7 additive kernel to its training residuals, with the existing ten options: identity/no correction, or fraction {0.1,0.3,0.6} crossed with kernel ridge {0.1,1,10}. One of 40 options is selected globally in three inner whole-patient folds. The kernel input standardization remains that of the fitting own-drug base, so the change is specifically the base conditional reconstruction. Identity/own-drug options come first for deterministic ties. No target-specific or orientation-specific option selection.

## Task and evaluation
119 Lib1 TRAIN samples, 59 whole patients, 24 fixed normalized log-dose AUCs. Exactly 64 distinct native doses, 32 physical wells per plate per alternative layout; eight targets have two doses and sixteen have three, unchanged. Acquisition is rebuilt using fitting rows only. Average A/B losses, never their prediction vectors. Five original outer patient folds, three regenerated inner patient folds in each outer-training split. Full curve covariance, means, scales, factor fits and kernel centering must be rebuilt strictly inside each fitting split. No global outer OOF predictions become training features.

The first ten options must reproduce operating bandwidth-0.7 MSE 0.0010582750420801538 within 1e-12. Retained scientific candidate MSE 0.001042745722096212, p90 0.037419695944064885, is only a saved comparator. Eligibility for a separate full numerical replay requires lower MSE, >=30 patient wins, 5/5 favorable outer folds and nonworse p90 versus BOTH references, and the original measurement contract. Meeting half-error additionally requires MSE <=0.000521372861048106; a smaller gain will not be called 2x better. Report all directions. No automatic promotion or submission change.

## Integrity checks and publication
Before any candidate fit, establish the deterministic full-curve quadrature map and verify it reconstructs the frozen targets. Synthetic tests check constant/linear quadrature, Gaussian conditional equivalence, exact all-observed reconstruction, PSD covariance, patient weighting, and malformed inputs. During evaluation poison all unpurchased query values. Rebuild outer fold 0 after perturbing all its training-ineligible curve values and labels; using the original purchased query values, the fitted state and predictions must be invariant. Save all chosen outer models privately and independently replay their predictions without refitting. Record source/input hashes, software environment, physical plans, per-fold choices, and adverse slices. Private arrays remain local; public evidence is aggregate only.

Prespecified descriptive paired bootstrap: 100000 whole-patient resamples, seed 202610071236, selection-unadjusted. Covariance learning from repeated development patients and passing a software leakage test do not establish independent biological validation. No Protected22/Lib2 access, no new control or treatment measurements, no target/fold splicing, no automatic retries or outcome-driven menu changes.
